A program that draws a newspaper front page summing up Monday 23 November 2026 in one 1024x1024 image: 33 stories from every region, led by the collapse of COP31 in Antalya. Written in TypeScript (Node 22, standard library only) — a hand-built 5x7 bitmap font, a pixel buffer, and a hand-rolled PNG encoder. No network at run time; the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
